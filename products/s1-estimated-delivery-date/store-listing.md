## App details / description
```
To show an estimated delivery date on a Shopify product page, install
SupaDatewise, add its app block to an Online Store 2.0 product template near the
Add to cart button, and set processing time, daily cutoff, shipping window, and
working days. The app calculates and displays the shopper-facing date
automatically, without editing theme code. It can also show the estimate on cart
pages.

The estimate is calculated live from your own rules:

• Processing time — how many business days you need to prepare an order
• Daily cutoff — orders after your cutoff hour roll to the next day
• Shipping time — a minimum and maximum transit window
• Working days — weekends and non-shipping days are skipped automatically

Set it once and every product page stays accurate on its own. You control the
exact wording, the date format, and the locale, so the message reads naturally
for your customers (English, and any locale you choose for date formatting).

No theme code required. The delivery estimate is a drag-and-drop block you add
in the theme editor and place exactly where you want it — usually right under
the Add to cart button.

Fast, lightweight, and privacy-friendly: the estimate is calculated in the
shopper's browser and the app stores no customer personal data.

Start with a 7-day free trial.
```

## Key benefits (feature bullets)
```
1. Automatic "Get it by <date>" — updates itself based on the current date and your cutoff.
2. Rules that match reality — processing time, cutoff, shipping window, and working days.
3. No theme code — drag-and-drop block, placed wherever you want it.
4. Your words, your format — fully customizable message, date format, and locale.
5. Light and private — computed in-browser, stores no customer personal data.
```
