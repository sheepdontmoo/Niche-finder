# /acq-money — money model designer

Working on:

> $ARGUMENTS

Read `knowledge/acq/03-money-models.md` first. Read the matching file in
`business-context/` if one exists.

## Goal

> **Recoup CAC within 30 days**, so the same dollar can be recycled monthly.
> Growth then becomes a financing question, not a marketing question.

## Process

### 1. Establish the true numbers
- **CAC** — must include sales + marketing **labour**, not just ad spend. Operators
  routinely understate this by 2–3×. Challenge the number.
- **Gross profit** and margin % — never reason in revenue
- **LTGP** — lifetime *gross profit*, not lifetime revenue
- **FECC** — cash actually collected in the first 30 days

### 2. Compute and verdict
| Ratio | Target | Verdict |
|---|---|---|
| LTGP : CAC | > 3 | |
| FECC : CAC | > 2 | |
| Payback period | ≤ 30 days | |

Show the arithmetic.

### 3. Route by which test fails
- **FECC:CAC fails** → fix the **front end**: attraction offer, price, payment
  terms, upsell at point of sale, deposits, pre-payment
- **LTGP:CAC fails** → fix the **back end**: continuity, retention, expansion,
  price increases
- **Both pass but payback > 30 days** → shift cash earlier, not upward: annual
  billing, deposits, setup fees, point-of-sale upsell

### 4. Audit the four offer types
| Type | Have it? | Current | Recommendation |
|---|---|---|---|
| **Attraction** — stranger → first-time customer | | | |
| **Upsell** — at the moment of highest intent | | | |
| **Downsell** — recovers a "no" already paid for | | | |
| **Continuity** — recurring, predictable | | | |

Most businesses have only an attraction offer. Each missing type is a specific,
quantifiable amount of money being left on the table — quantify it.

### 5. Rebuild the sequence
Design the full sequence and **recompute payback**. Iterate until ≤ 30 days or
until you can state exactly why it's not achievable in this business.

### 6. Cash tactics needing no new customers
Pre-payment discounts, annual billing, deposits/setup fees, price increases with
a transition date, point-of-sale upsells. Quantify each against payback.

## Output

Before/after table of the four ratios, the redesigned offer sequence, and the
ordered list of changes with each one's effect on payback in days.

## Rules
- **Gross profit, never revenue.** Correct the user every time they slip.
- CAC includes labour. Push back on a suspiciously low CAC.
- Every "no" without a downsell is a fully-funded loss — price it.
- Cash timing beats cash amount for growth rate. Earlier > bigger.
