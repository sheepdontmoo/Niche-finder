# Zero-to-Range-Rover

Standalone venture. Own P&L, separate bank pot. **No debt, ever.**
Every product funds its own ads from its own revenue.

**Target:** €350k profit in 12 months.

## Strategy

Portfolio play: 30–50 parallel micro-products (Chrome extensions,
Shopify apps, Figma plugins). Power-law economics — most fail. Kill
losers weekly, feed winners. **Speed of shots > polish per shot.**

- **Wave 1:** 4 Chrome, 2 Shopify (start first — slow review), 2 Figma.

## Roles

- **Claude Code (engine):** research, specs, builds, listings, copy,
  scripts. Bias to shipping.
- **Darren (rails + face + judgment):** accounts, submissions, kill/keep
  calls, one content channel from Day 8. Never assigned work the engine
  can do itself.

## Gates (pre-agreed — not relitigated)

| Day | Gate |
|-----|------|
| 30  | 8 products live, first paid sale |
| 60  | bottom half killed, ≥€500 combined MRR |
| 90  | one product on €1k+ MRR trajectory, else full re-decide |

## Rules

1. v1 ships in ≤5 days or the product is descoped.
2. Evidence over recall: marketplace data, reviews, platform docs —
   link it or mark `UNVERIFIED`.
3. No silent assumptions. No over-engineering. Scope stays limited.
   Verify success criteria before calling anything done.
4. No deception: nothing where the buyer is misled about what they get.
5. Weekly output: portfolio table — product, status, installs, MRR,
   verdict (kill/hold/feed). See [`docs/portfolio.md`](docs/portfolio.md).
