+ Clay enrichment + Gmail/Resend + web research). We sell the output businesses already
pay agencies four figures a month for: **researched, enriched, verified prospect lists
with personalized outreach copy** — delivered in days, not weeks.

Why this wins the 90-day race:
- **Zero inventory, near-zero COGS.** The deliverable is produced with tools we have.
- **High ticket, fast delivery.** €290–€900 per unit, delivered in 1–3 days.
- **Proven, evergreen demand.** Every agency, recruiter, SaaS, and consultancy buys leads.
- **Provable quality upfront.** We can show a real sample list before anyone pays — no
  trust gap.
- **Compounds into retainers.** One-off buyers convert to monthly recurring.

## 4. Funnel

1. **Pick a beachhead niche** we can credibly serve and that visibly buys leads
   (recommended first: **B2B lead-gen / marketing agencies** — they resell, so they buy
   volume and understand the value instantly).
2. **Build a real sample deliverable** for that niche (proof of quality — see
   `delivery/`). Doubles as the top-of-funnel magnet.
3. **Landing page** (`landing/index.html`) with the offer + sample + payment link. Ready
   to publish on approval.
4. **Outreach** (`assets/cold-outreach.md`) — personalized, low-volume, high-fit. Human
   approves every send. Lead with the sample, not a pitch.
5. **Close** via Stripe payment link / invoice. Collect upfront (or 50/50 on retainers).
6. **Deliver** with the Niche-finder engine, over-deliver, ask for referral + review.
7. **Convert** one-off buyers to retainers.

## 5. Approval gates (I will STOP and ask before each)

- Publishing the landing page or any public content
- Any live email/message send or follow-up
- Creating/changing any account (Stripe, domain, social, tools)
- Requesting payment / sending an invoice / sharing payment details
- Spending any money
- Anything touching identity, passwords, or 2FA

## 6. What I need from the human to start firing

1. **Beachhead niche + any warm channel** (network, list, or social) we can activate —
   the single biggest speed lever. Cold-only works but is slower.
2. **Payment rail** (Stripe recommended) set up under your identity so collection is
   verifiable.
3. **Budget appetite** — a small domain (~€10) + optional Clay/enrichment credits would
   materially speed things; each spend still needs explicit approval and is reimbursed
   through growth.
4. **Green light** to build the first real sample list, then to publish + start outreach.
