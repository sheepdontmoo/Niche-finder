# Business context — <BUSINESS NAME>

Copy this file to `business-context/<business-slug>.md` and fill it in, one file
per business. The `/acq` command reads these to run a diagnosis.

Acquisition.com's own $35k workshop requires operators to submit metrics **two
months in advance** so the team can identify the constraint before anyone talks.
This file is that submission. **The quality of the diagnosis is capped by the
quality of this file** — "I don't know" is a valid and useful answer, but guessing
is not.
